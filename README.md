# METODI NUMERICI
Questo è il mio primo read me. Essenzialmente ciò che faremo qui sarà provare a fare codici in c (linguaggio a me sconosciuto) per poter fare simulazioni numeriche.
Come navigare la repository:
- la cartella include contiene tutti i file .h da richiamare nei vari main
  
- la cartella lib contiene i file .c associati ai file .h e contengono funzioni che vengono spesso riciclate nei vari progetti
  
- modulo 1 contiene tutto ciò che è stato fatto in funzione dell'esame di metodi numerici del modulo MCMC
    - analisi contiene i file in jupyter notebook con l'analisi dati di ciò che abbiamo ottenuto dalle simulazioni numeriche
        - grafici contiene i grafici prodotti dalle analisi dai jupyter notebook
    - dati contiene i dati provenienti dalle simulazioni numeriche contenute in modulo 1
  
 Stessa cosa per modulo 2 e modulo 3

- prova progetti contiene varie esercitazioni fatte per prepararsi alla scrittura dei codici ciccioni dei moduli
    - analisi contiene i file in jupyter notebook con l'analisi dati di ciò che abbiamo ottenuto dalle simulazioni numeriche
        - grafici contiene i grafici prodotti dalle analisi dai jupyter notebook
    - dati contiene i dati provenienti dalle simulazioni numeriche contenute in prova progetti
